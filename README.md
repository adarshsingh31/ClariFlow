# ClariFlow

A full-stack TypeScript starter with separate frontend and backend applications.

## Structure

- `frontend`: Vite, React, and TypeScript app
- `backend`: Express and TypeScript API

## Setup

Install dependencies for the root tools and both applications:

```bash
npm run install:all
```

Start frontend and backend together:

```bash
npm run dev
```

The frontend runs at `http://localhost:5173` and the API runs at `http://localhost:4000`.
The API health check is available at `http://localhost:4000/api/health`.

Build both applications:

```bash
npm run build
```
